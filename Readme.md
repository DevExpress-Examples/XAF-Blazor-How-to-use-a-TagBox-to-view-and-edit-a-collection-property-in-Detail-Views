# XAF Blazor - How to use a TagBox to view and edit a collection property in Detail Views

⛔ DEPRECATED. This example creates a custom XAF Property Editor based on our [DxTagBox](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxTagBox-2) component. Starting from v25.1, XAF ASP.NET Core Blazor includes a [TagBoxPropertyEditor](https://docs.devexpress.com/eXpressAppFramework/113568/business-model-design-orm/data-types-supported-by-built-in-editors/collection-properties?v=25.1#tagboxpropertyeditor).
